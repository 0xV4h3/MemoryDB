# MemoryDB ⚡

> **Store. Stream. Persist — lightweight file-based data engine with MemoryDB.**

MemoryDB is a minimal data solution that brings together a file-based document database and a decoupled in-memory TTL cache. It demonstrates how to handle persistence, serialization strategies, and memory lifecycles without external database overhead.

---

## 🛠️ Features

* **File Storage:** Document tracking using extensible serialization strategies.
* **Custom Binary Stream:** Compact file storage built directly for raw streams.
* **TTL Cache:** Memory storage featuring active and passive expiration.
* **Reactive Architecture:** Event-driven database triggers and cache expiration hooks.
